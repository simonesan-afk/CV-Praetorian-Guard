# Security Policy

## Supported Versions

This project is an educational prompt and does not include executable code,
network services, databases, or production deployments.

As such, there are no supported versions in the traditional software-security
sense. **PRAETOR v7.1 is the current stable version of the prompt**, and all
published versions are provided "as-is" for educational and personal
self-assessment use only.

---

## Reporting a Vulnerability

This project does not directly process, store, or transmit user data.
However, potential security, privacy, or safety concerns may include:

* Accidental exposure of personal or sensitive information (PII)
* Prompt behavior that could weaken privacy or safety safeguards
* Misuse of the prompt for hiring, screening, ranking, or employment decision-making
* Prompt injection or other attempts to alter the defined safety boundaries
* Other ethical or safety concerns related to prompt behavior

If you believe you have identified a security, privacy, or ethical issue:

1. **Do NOT include real personal or sensitive data** in your report.
2. Open a GitHub Issue describing the concern clearly and concisely.
3. Label the issue as **Security**, **Privacy**, or **Ethical Concern** where applicable.

Reports will be reviewed on a best-effort basis.
There is no guaranteed response time or obligation to provide fixes.

---

## Data Safety Notice

Users are strongly advised to redact unnecessary personal data before using this
prompt with any AI system.

PRAETOR is designed for personal analysis of an individual's own CV and a Job
Description. The repository itself does not collect or store CVs or other user
data.

Users should follow the privacy, retention, and data-handling policies of the
AI service they choose and should avoid submitting confidential or unnecessary
personal information.
