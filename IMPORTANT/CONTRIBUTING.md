Contributing to CV-Praetorian-Guard

Thank you for your interest in PRAETOR (CV-Praetorian-Guard).

⛔ No Contributions Accepted

At this stage, this repository is closed to external contributions.

This project is released as a specific, stable version (v7.1) intended for personal educational self-assessment only. The logic contains carefully tuned heuristic parameters and ethical safety guardrails (Privacy & Anti-Bias) that must remain strictly consistent.

Why?
Safety Integrity: The prompt includes strict protocols for PII detection and ethical boundaries that we do not want accidentally weakened by third-party edits.
Stability: This is a stable release. We are not looking to change the scoring logic or the heuristic model at this time.
🐛 Found a Bug?

If you discover a critical failure (e.g., the prompt hallucinates, misinterprets the input, or fails to protect privacy), please simply open an Issue to report it. Do not submit a Pull Request.

You are free to use this prompt for your own personal self-assessment as described in the disclaimer.
